Case Study

作业说明
The submission must consist of two files: a PDF report and an Excel file containing calculations:

The PDF report, including all figures and tables, must not exceed 5 pages.
The Excel file for calculations has no sheet limit.
These two files must be combined into a single ZIP archive for submission.
The names and student numbers of all group members must be clearly stated on the first page of the PDF report.
