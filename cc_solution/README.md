## 分析方法

### 建模思路

脚本按作业四个步骤组织：

**Step 1 — 现金流模型**

以 2026-01-01 为期初（Period 0），按年度构建税后净现金流：

```
年度 CF = 收入 - 运营成本 - 企业所得税(25%)
```

三类收入：
- **租金收入** = Σ(各楼层可租面积 × 日租金) × 出租率 × 有效收租天数
  - 2026 年仅计 184 天（7月1日起，3个月免租期后）
- **停车费收入** = 车位数(1005) × 3元/时 × 6时/天 × 使用率 × 运营天数
- **物业费收入** = 已租面积 × 10元/㎡/月 × 运营月数（免租期内照收）

六类运营成本：
- 人事、市场推广、行政：给定年度基准值 × 时间系数 × 各年增长率
- 维保维修（基本）：15元/㎡(GFA)/年 × 时间系数 × 增长率
- 资本性改造：当年租金收入 × 2.5%
- 物业管理：30元/㎡(GFA)/年；能耗：40元/㎡(GFA)/年

2026 年时间系数 = 9/12（仅运营 9 个月），2027 年起为 1。

退出价值（2029年末）采用永续年金：

```
退出价值 = 2029年税后净CF / 8%   （不计税）
```

**Step 2 — 收购价格估算**

令 NPV = 0，以 MARR = 12% 反推收购对价 P：

```
0 = -(P×1.03 + 其他费用1100万 + 开业成本1000万)
    + CF₁/1.12 + CF₂/1.12² + CF₃/1.12³ + (CF₄+退出价值)/1.12⁴

P = (未来CF现值合计 - 2100万) / 1.03
```

**Step 3 — 敏感性分析**

枚举稳定期出租率（70%–95%）× 2029 年租金增长率（-3%–8%），对每种组合重新运行上述计算，输出收购价格矩阵（6×5 共 30 个情景）。

**Step 4 — 开放性分析**

报告中针对潜在风险（招商执行、主力店集中、退出流动性等）和运营策略（业态配比、租户选择逻辑）进行定性分析。

## 使用方式


同时生成/刷新：
- `宁波怡丰汇投资分析.xlsx`
- `投资分析报告.docx`

### 修改假设参数

所有输入参数集中在脚本顶部的"PARAMETERS"区块（约第 20–80 行），修改后重新运行即可：

| 参数变量 | 含义 |
|---------|------|
| `lease_params` | 各年出租率和租金增长率 |
| `parking` | 各年停车使用率 |
| `MARR` | 折现率（默认 12%） |
| `EXIT_CAP_RATE` | 退出资本化率（默认 8%） |
| `OCC_LIST` / `RENT_GROWTH_LIST` | 敏感性分析枚举范围 |
| `rent_rate` | 各楼层日租金（元/天/㎡） |

例如，将稳定期出租率改为 90%：

```python
lease_params = {
    2026: {'occ': 0.80, 'rent_g': 0.00},
    2027: {'occ': 0.90, 'rent_g': 0.00},  # 改这里
    2028: {'occ': 0.90, 'rent_g': 0.00},
    2029: {'occ': 0.90, 'rent_g': 0.03},
}
```
