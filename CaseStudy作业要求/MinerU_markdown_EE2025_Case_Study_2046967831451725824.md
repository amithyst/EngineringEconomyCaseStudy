# 3 投资逻辑与定价要点

从投资人的角度来看，怡丰汇项目存在明显的挑战：目前商场现金流不足，短期内难以支撑高回报，招商及改造需要额外投入。但也蕴含潜在机遇：项目区位优势明显，未来地铁通车将进一步带动人流。并且周边居住区人口密度高，具备较强的消费潜力。除此之外，与区域内可比项目相比，目前的出租率与租金均处于低位，提升空间巨大。在此背景下，需基于年度口径的现金流测算，并以 $12 \%$ 的MARR为基准，合理评估项目的收购价格。

# 4 财务分析与关键问题

在投资分析中，核心是建立现金流模型、在预期的投资回报率下估计合理的收购价格（收购对价）。进一步通过敏感性分析和战略判断对项目进行投资可行性的综合评估。

请你站在投资委员会成员的角度，按照以下四个步骤进行分析：

# Step 1：建立现金流模型

本阶段的目标是基于Excel文件中提供的基础假设数据，系统理解项目的现金流结构。

首先，根据项目时间线划分现金流阶段，以 2026 年 1 月 1 日为期初（Period 0），2026

年为项目改造期，2027-2029年为项目平稳期，构建现金流模型（不考虑折旧），计算各年度的现金流：

（1）投资成本。2026年初一次性支付收购对价，交易契税（收购对价 $\times$ 契税税率），其他交易相关费用以及商场开业成本；

（2）租金收入。项目将于 2026年4月1日开业，且首年设有 3个月免租期，即2026年仅收取6个月租金；2027年起，项目进入稳定运营阶段，租金按照全年收取，且依照出租率和租金增长率逐年调整；

（3）停车费收入。所有楼层的产权车位与无产权车位实行统一运营管理，全部计入停车收费经营收益，收入按照每年商场实际运营的天数计算；

（4）物业费收入。按实际出租面积计取。处于免租期时，租金免收，但物业费仍照常收取；

（5）运营成本。因首年运营时间仅有9个月，运营成本（人事、市场推广、维保维修、物业管理、能耗、行政）依照建筑面积，按全年的实际运营时间折算。2027年起，项目进入稳定运营阶段，费用按照全年计算，且依据费用增长率逐年调整；

（6）退出价值：假设2029年12月31日后项目可持续产生稳定现金流，采用永续年金模型（ $( \mathrm { i } \mathrm { = } 8 \% )$ ）计算退出价值；

（7）税收成本：依据每年营业利润需要缴纳的企业所得税，统一按 25%的固定税率计算，退出价值不计税。

在现金流测算过程中，应重点分析以下问题：现金流是否能逐季度改善？改造期与稳定期的现金流差异有多大？

# Step 2：收购价格估算

在构建现金流模型后，你需要在MARR为 $1 2 \%$ 的基准，给出对该项目的收购价格建议。

由于商业地产存在高度不确定性，因此你需要检验关键变量变化对结果的影响。请在Excel中调整租赁相关假设数据，比较结果的差异。比如在不同的出租率，租金增长率的估计下，重新计算现金流和合理的收购价格，观察结果随租赁相关参数的变化程度。
