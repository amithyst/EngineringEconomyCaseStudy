# Work Plan

## Phase 1: Setup

- organize source materials
- define branch workflow
- document assignment requirements

## Phase 2: Modeling

- map the project timeline
- define each cash flow component
- create acquisition price logic from the target MARR
- define terminal value treatment and tax treatment

## Phase 3: Sensitivity Analysis

- vary occupancy assumptions
- vary rent growth assumptions
- summarize impact on acquisition price and NPV

## Phase 4: Final Writeup

- draft the financial conclusion
- draft the strategic and operational risk section
- draft tenant mix and operating recommendations

## Deliverables

- a clean workbook or generated tables showing the annual cash flows
- a clear acquisition price recommendation
- a sensitivity table or chart
- a concise final writeup suitable for submission
